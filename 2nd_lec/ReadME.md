# Python Beginner Practice Notes

This project is a Python learning script that introduces students to basic programming ideas using simple examples and exercises.

## What is in this code?

This file covers the following topics:

- Arithmetic operators:
  - addition
  - subtraction
  - multiplication
  - division
  - floor division
  - exponentiation

- Augmented assignment operators:
  - `+=`
  - examples of updating variable values

- Operator precedence:
  - understanding the order in which Python evaluates expressions

- Math functions:
  - `round()`
  - `abs()`
  - `math.ceil()`
  - `math.floor()`
  - `math.trunc()`
  - `math.factorial()`
  - `math.isqrt()`
  - `math.comb()`
  - `math.perm()`
  - `math.fmod()`
  - `math.modf()`

- Conditional statements:
  - `if`
  - `elif`
  - `else`

- Logical and comparison operators:
  - checking conditions using boolean logic

- While loop:
  - repeating code until a condition is no longer true

- Input handling:
  - taking user input with `input()`

- Example real-world scenario:
  - calculating a house down payment

## What students will learn

Students will learn how to:

- write and understand basic Python expressions
- perform calculations using operators
- work with variables and reassignment
- use mathematical functions from Python's `math` module
- make decisions with conditional logic
- control program flow using loops
- validate user input
- create small real-life programs using Python logic

## Example goals of this lesson

This code helps students build a foundation in:

- Python syntax
- problem solving
- logic building
- beginner-level programming structure

## Notes

This script is meant for learning and practice. It is a simple introduction to Python and is ideal for beginners who are starting to understand how programs make decisions and repeat actions.
