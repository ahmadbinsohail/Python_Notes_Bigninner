## Lessons at the Workspace Root

### `1st_lec.py` - Input, strings, and conversion

Introduces `print()` and `input()`, string capitalization, f-strings and concatenation, converting an entered weight from pounds to kilograms, checking a value's type, quotes and multiline strings, string slicing, `len()`, and the `in` operator. Run it in a terminal because it asks for several inputs.

### `2nd_lec.py` - Numbers, operators, conditions, and loops

Shows arithmetic operators (`/`, `//`, `**`), augmented assignment, operator precedence notes, built-in numeric functions, and functions from `math`. It also demonstrates `if`/`elif`/`else`, comparison and logical operators, and a `while` loop that validates a name's length.

### `3rd_lec.py` - Collections, loops, and functions

Covers `for` loops and `range()`, accumulating a shopping-cart total, nested loops, lists and list methods, finding a maximum, a 2D list, removing duplicate values, tuple unpacking, and dictionaries. It includes a phone-digit-to-word exercise and functions with positional and keyword arguments, return values, and an emoji-conversion function.

### `4th_Lec_(Classes).py` - Classes and inheritance

Defines a `Human` class with a constructor, attributes, class-level defaults, and `speak()` and `eat()` methods. It creates and uses `Human` objects, then defines `Men` and `Women` as subclasses. The subclasses call the parent constructor with `super()` and add a `hair` attribute.

### `Exeptions_(handing errors).py` - Exception handling

Reads an integer inside a `try` block and divides 100 by it. `ValueError` handles input that cannot be converted to an integer; `ZeroDivisionError` handles entering zero. The script prints a message for either error rather than displaying a traceback.

### `Directories.py` - Paths

Uses `pathlib.Path` to create a path, print the current working directory, and check whether the path exists. The path currently written in the script appears to be a machine-specific path; replace it with a path valid on your computer when practicing.

### `Modules 5th lec.py` - Imports, packages, and random values

Shows importing a local utility/module (currently commented out), importing `shipping` from the `pacakage` package and calling `func_ship()`, and using Python's `random` module to generate numbers and choose a name at random.

### `Modules_5th_lec.py` - Importing local modules

Imports `utils` and attempts to import `carengine`, then calls their functions. The workspace file is named `Projects/car_engine.py`, not `carengine.py`, and is in a subfolder. As written, this import is not aligned with the current file layout; see the import notes below.

### `utils.py` - A reusable helper function

Defines `max(l)`, which loops over a list and returns its largest element. It is imported by the module lesson and other projects. The function expects a non-empty list of comparable values. Its parameter name `l` shadows the visual shape of the number `1`, so use care when reading it.

## Small Projects

### `Projects/car_engine.py` - Car command loop

Defines an `engine()` command loop that accepts `start`, `stop`, and `exit`, rejects unrecognized commands, and tracks whether the car is started. The function is called at the bottom of the file, so running or importing this module starts the interactive prompt. The current `stop` branch prints that the engine stopped but does not reset the `started` state.

### `Projects/dice_game.app.py` - Dice roller

Defines methods to ask how many dice to roll and, after the user enters `r`, print a random value from 1 to 6 for each die. Invalid numeric input is caught. The script runs the prompts at the bottom. The methods are written without `self` or `@staticmethod`, and the module is also duplicated as `Projects/modules.py`; these are beginner examples, not a polished reusable class API.

### `Projects/modules.py` - Dice module example

Contains the same `Dice` class and methods as `dice_game.app.py`, but does not start the input flow when imported. It is an example of keeping definitions in a module for reuse.

### `Projects/Guess_game.py` - Number guessing game

The player tries to guess a stored number, with up to three guesses, and can exit, restart, or enter an admin flow to change the number or password. The admin password is hard-coded as `admin123` for demonstration only; do not use this pattern for real authentication. The script is interactive and expects numeric menu entries.

### `Projects/weight_conventor.py` - Weight converter

Reads a numeric weight, asks whether it is in pounds (`l`) or kilograms (`k`), then converts and prints the other unit. It catches non-numeric weight input. The filename uses the spelling `conventor` in the workspace.

### `Projects/word_to_emoji.py` - Text-to-emoji loop

Repeatedly accepts a message, replaces recognized words such as `happy`, `sad`, and `love` with emoji, leaves unrecognized words as text, and exits when the user types `exit`.

## Automation Project

### `Projects/Automation/main.app.py` - Spreadsheet price adjustment

Uses `openpyxl` to open `transactions.xlsx` from the same folder, read `Sheet1`, create a `Corrected Price` column using 90% of the values in column C, add a 3D bar chart, and save the result as `1transactions.xlsx`. It catches `PermissionError` and asks the user to close the workbook if it is open. It expects the workbook to contain a worksheet named `Sheet1` and numeric prices in column C.

## Machine Learning and Data Project

### `Projects/ML/main.py` - Read and inspect CSV data

Uses `pandas` and `pathlib` to locate `data/scrapped_data.csv` relative to the script, reads it into a DataFrame, and prints its shape and `describe` attribute. To display descriptive statistics, the expression should be `df.describe()`; without parentheses, the current code prints the method object rather than the statistics.

### `Projects/ML/main.ipynb` - Notebook version

A three-code-cell Jupyter notebook imports pandas and NumPy, attempts to load `data/scrapped_data.csv`, prints the DataFrame's shape, and references its descriptive-statistics method. It is intended for running cells interactively in VS Code with a selected Python kernel.

The first cell uses `__file__` to locate the data folder. Jupyter notebook cells normally do not define `__file__`, so that line may raise `NameError`. In a notebook, use a path based on the notebook's working directory (for example, `Path("data")` if the kernel starts in `Projects/ML`) or another explicit valid path. As in `main.py`, call `df.describe()` to compute the statistics.

## Running the Examples

Open the workspace folder in VS Code, open a terminal at the workspace root, and run an individual script with:

```powershell
py .\1st_lec.py
```

Replace the script path with the lesson or project you want to run. Interactive scripts wait for terminal input. Avoid running many interactive scripts simultaneously in the same terminal.

For the notebook, install the VS Code Python and Jupyter extensions, open `Projects/ML/main.ipynb`, choose a Python kernel, and run cells individually. A virtual environment can be created from the workspace root with:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install ipykernel pandas numpy openpyxl
```

Select the `.venv` environment as the notebook kernel. `pandas` and `numpy` are used by the ML examples; `openpyxl` is used by the spreadsheet automation script. The remaining examples primarily use Python's standard library.

## Import and Path Notes

- `Projects/Modules_5th_lec.py` imports `carengine`, but the existing file is `Projects/car_engine.py`. Python module imports use the filename without `.py`, so the name and import must be made consistent before that script can run as intended.
- When importing project files from a lesson at the workspace root, remember that `Projects` is a subfolder. Run from the workspace root and use a package-style import such as `from Projects import car_engine`, or adjust the module search path. If a module starts interactive work at import time, importing it also starts that work.
- `Directories.py` contains a specific Windows path and may need to be updated for another machine.
- File names with spaces, parentheses, or multiple dots should be quoted when typed as terminal paths.
